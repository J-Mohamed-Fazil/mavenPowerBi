# Maven Market - Power BI Project

This repository contains the dataset and Power BI report (`.pbix`) for the Maven Market business intelligence project.

## Project Contents

- **`TheMavenPbi.pbix`**: Power BI Desktop project file containing data models, relationships, DAX measures, and interactive report dashboards.
- **Data Files (CSV)**:
  - `MavenMarket_Calendar.csv` — Date dimension table
  - `MavenMarket_Customers.csv` — Customer profile and demographic details
  - `MavenMarket_Products.csv` — Product catalog, pricing, and category hierarchies
  - `MavenMarket_Regions.csv` — Store regional classifications
  - `MavenMarket_Stores.csv` — Retail store locations and operating details
  - `MavenMarket_Returns_1997-1998.csv` — Product return records (1997–1998)
  - `MavenMarket_Transactions_1997.csv` — Transaction history for 1997
  - `MavenMarket_Transactions_1998.csv` — Transaction history for 1998
